# nb-borrow 单 INC 交叠资格化测试

## 测试范围

- 环境：`nb-borrow`，昇腾 910B2C，CANN 9.1.0-beta.3。
- 卡位：INC 为物理卡 0；W2 的 worker 为物理卡 1/2；W4 的 worker 为
  物理卡 1/2/3/4。
- 实时拓扑检查：所有 INC—worker 连接均为 HCCS。
- 数据形状：每个算子的物理通信量均为 128 MiB；W2 使用 top-k=2，W4
  使用 top-k=4。
- 计时：采用设备周期的最慢 rank 时间 `max(rank_us)`；初始化、结果校验
  和主机唤醒不计入算子时间。
- AIV：实时检测到每卡 48 个 AIV；日志显示 Dispatch 在 INC 上使用 16
  条 lane，Combine 使用 32 个 owner。这是硬件静态资源策略的结果，不是
  针对本次数据形状调参。

## 修正后的理论口径

先前使用 `max(Td,Tc)` 作为理论最短时间，只是完全不考虑资源争用的调度
极限。两个等长任务在这个定义下天然接近 2 倍，与 worker 数量无关，不能作为
nb 拓扑下的带宽理论。本报告不再把它称为“理论收益”。

对 balanced case，设 Dispatch 和 Combine 的计量分子分别为 `D`、`U`，目标
worker 数为 `R`，top-k 为 `K`。两个算子同时运行时，INC 两个方向需要承载：

```text
下行字节 = D + U/K       # Dispatch fanout + Combine 回传
上行字节 = D/R + U       # Dispatch 上传 + Combine 汇聚

T下行 = 下行字节 / 本规模 duplex 下行 roofline
T上行 = 上行字节 / 本规模 duplex 上行 roofline
拓扑理论最短时间 = max(Td, Tc, T下行, T上行)
拓扑理论收益     = 1 - 拓扑理论最短时间/(Td+Tc)
真实收益         = 1 - T并发/(Td+Tc)
```

本轮 `D=U=128 MiB`，并直接使用 nb 已有正式 put-only duplex 最小值，避免用
偶发峰值抬高理论：W2 上行/下行为 37.615/37.611 GB/s，W4 为
74.932/73.139 GB/s。

## 正确性与结论

每个规模执行了 2 次 Dispatch 单独运行、2 次 Combine 单独运行、3 次同时
启动、1 次 Dispatch 提前 500 微秒和 1 次 Combine 提前 500 微秒。18/18
个 case 的全部 rank 均通过正确性检查；10/10 个并发 case 均存在正的设备
执行区间交集，没有发现结果错误、超时、共同 deadline 错误或残留 NPU 进程。

当前代码确实能让两个独立 SHMEM session 在同一 INC 上并发执行，不是只在
主机侧同时提交。按修正后的拓扑理论，W4 的同时启动真实收益为 22.20%，达到
理论收益的 57.80%；W2 的真实收益为 15.38%，达到理论收益的 69.81%。W4 的
Dispatch 提前 500 微秒 case 最好，真实收益为 29.52%，但它是单次错峰样本，
不能替代多次稳定性统计。

本轮属于真机资格化测试，不是正式 H11 稳定性关门测试：单独运行只有 2 次，
同时启动只有 3 次，尚未满足正式的 warmup≥3、measure≥10 要求。

`summary.json` 保存机器可读汇总；每个 case 子目录均保留 `case.json`、逐 rank
日志、物理卡映射、设备计时和正确性证据。原有 yuanmingyu 数据没有修改。
